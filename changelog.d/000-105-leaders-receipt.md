## 2026-11-01 (#000: 105-leaders-receipt — the NHL leaders-order receipt, read-only: leaders[0] at every pregame poll against the T+20 eventual starter; addendum 200 item 1, #105)
- scripts/nhl_leaders_order_receipt.py (ARCHITECT 2026-11-01 13:15 ET, addendum 200 item 1; lane nhl, the 11-05 step), read-only, no DB, no network, writes nothing. It takes one or more of the probe's `--save` directories (`<game id>_<endpoint>_<label>.json`, the probe's own write line; labels T-120 .. T-0 and T+20). It runs in a checkout or as a copy in /tmp with `PYTHONPATH` naming a checkout (#757's form).
  - Per directory, game and side: the landing page's `matchup.goalieComparison.<side>Team.leaders[0]` (playerId, the member's name beside it) at every pregame poll T-120, T-90, T-60, T-45, T-35, T-30, T-15, T-0, in poll order so a flip shows. A missing landing file, a file that does not parse, no goalieComparison, no or an empty leaders list, or a leaders[0] with no playerId is `missing at <label>`, its reason printed, counted.
  - The eventual starter is read by the ingest's own `src.ingestion.nhl_goalies.boxscore_goalies` on the T+20 boxscore (called, never copied; law 1): the side's goalie with toi above zero. Two or more above zero is `two in net`, counted and never chosen. None, no T+20 file, a file that does not parse, or a boxscore the ingest refuses (goalie lists not sided one home + one away) is `eventual starter unread`. Law 4: one goalie above zero beside a goalie whose toi the ingest cannot read is also unread, the reason printed (a reading for the architect to confirm; it moves n only on a boxscore with an unread toi). Limitation: a goalie the ingest drops for want of an id is not seen.
  - Each side's line ends AGREES / DIFFERS / UNREAD at T-35 and at T-120 and the flip count (leaders[0] changing between consecutive answered pregame polls; a missing poll is skipped, never a flip by itself).
  - The summary, per directory and across all: at T-35 agrees a of n (n = sides with a leaders[0] at T-35 AND a read eventual starter); the same at T-120; missing at T-35; eventual unread; two in net; sides with at least one flip; games read; then missing by label, files that did not parse, files not of the name form. Last line `NHL-LEADERS-ORDER-RECEIPT {...}`. Game ids carry the payload's `AWAY @ HOME` abbrevs where a payload carries both.
  - A directory named twice (or by two spellings of one path) is read once, the repeat printed and counted.
  - Exit 0 on a complete read; 2 refused: no directory, not a directory, a directory under data/, no file of the name form, or `src.ingestion.nhl_goalies` not importable.
