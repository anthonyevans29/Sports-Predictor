- **3(a), the lookup:** `sync_matches`' prefetch (the 2026-09-23 O(1) cache, kept) is built by `service.match_cache`: for a source that is not SPORT_WIDE each row is keyed (provider id, season), the season in its stored form (`season_key`: the string stripped; blank is unknown). Each listed row is looked up by its OWN season, so a sync without `--season` that lists several seasons scopes row by row. The cache=None path (no caller in src/) builds the same cache over the competition instead of the old source-id-only full scan of every row (`_find_match_by_source`, removed). `intl_history`'s own prefetch uses `match_cache` too. `_mismatch_on_unknown_team` (addendum 297 C(i)) reads only the listing's own season's row.
- **3(b), the collision:** a stored row of another season carrying the listed id is listed on `SyncResult.provider_id_collision` as (stored id, its season, the listing's id) and never written; the listing goes on to the re-key fallback (its own season's) and otherwise creates its own row (its season, its home/away, the provider id in `external_ids`). `sync-matches` (each `--seasons` season and the tennis path too) prints `provider_id_collision N: <stored id> (<season>) ← <listing id>, …` on its own line right after the summary, zero included; the scores-by-team line stays the tail's last line. The admin UI's sync job logs it; `intl-sync` prints it.
- **Law 4, an unknown season:** a listing that names no season, or one whose season finds no row while a row of unknown season carries the id, writes nothing (neither an update nor a new row), is counted in `skipped`, and prints `provider_id_season_unknown N: <listing ids>` (only when N > 0).
- **3(c), the re-key index:** the natural-key pairs are keyed (season, home, away), the `<source>_prev` history (provider id, season); the NCAA placeholder window reads the same pairs. An annual rematch is never a re-key target.
- **3(e):** `score_orientation`'s docstring gains the line; no code change to the chain. SPORT_WIDE_SOURCES (`mlb_stats_api`, #569) is unchanged: a gamePk is looked up across the sport's rows, whatever the season.
