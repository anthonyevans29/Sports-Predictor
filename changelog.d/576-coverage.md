## 2026-10-17 (#576: coverage — ARCHITECT addendum 107 item C7)
- cli.py `coverage [--date YYYY-MM-DD]`, built in deploy/hosting/coverage_map.py: the day's coverage, read-only. The DB is opened mode=ro (a missing file is refused, never created); no row or export is written; no provider call. On a WAL file SQLite itself may leave its -wal/-shm sidecars, as for every `ro_connect` reader.
  - The day: `--date`, default today in US Eastern. A game belongs to the day by its US Eastern date (`closing.ny_date`). Void games (`closing.VOID`) are named and not counted.
  - One line per competition with games that day: the games; LIVE, SHADOW, MARKET-ONLY or UNKNOWN, with where it was read; the stored prediction rows by model_version with their computed_at in ET (`latest …`, or `computed <earliest> to <latest>` when the rows differ, so an old row is never hidden behind a fresh one; the map keeps each game's own), and the games with none; the closing groups the watch will run (`started …`, `a closing finished with …`, then `T-35 HH:MM ET [match ids] → exports/closing_<FAMILY>_<start>.json`, marked `(due now)` from T-35 to T-5, or `inside T-5: no attempt, no file` for a miss).
  - The closing pieces are closing.py's own: `groups()` on `due()`'s own inputs (the stored games plus the unpaged called-off ones, `with_called_off`, less the games a closing has finished with, `covered_ids` from the watch's receipts, read-only), over the family's games of the day at now; `RUN_LEAD_MIN`, `NO_ATTEMPT_INSIDE_MIN`, `closing_name()`, `CLOSING_FILE_DIR`. A family this machine refuses (`_family_refusal`: SP_SKIP_FAMILIES, MLB on the host) prints `closing: refused here (…)`; receipts that cannot be read print `closing: not shown (…)`.
  - The status: LIVE where a closing family covers the competition (`closing.FAMILIES[fam]['comps']`, the families of chains.CLOSING_FAMILIES, C1), or the roadmap lane named for it (lane id = competition code) is live and its registry entry, if the lane names one, is in production. SHADOW where that lane is confirming and its registry entry, if it names one, is too. MARKET-ONLY for a lane in any other state. UNKNOWN, with the reason, where nothing names the competition, the lane and the registry disagree, or a file cannot be read.
  - Then the gaps in capitals: a LIVE competition with a game that has no row, `PL: 4 GAMES, 0 PREDICTION ROWS — soccer-prematch has not run`, or `MLB: 2 GAMES, 1 PREDICTION ROW, NONE FOR 50549`; none for a family this machine refuses. The hint names the chain whose predict step matches the closing chain's word for word (SOCCER soccer-prematch, MLB mlb-preslate, NFL nfl-predict); no chain found, no hint. Then one line naming the UNKNOWN competitions, for which no gap is judged. No chain runs a predict step for a SHADOW or MARKET-ONLY competition, so no gap is claimed for them.
  - Exit 0 whatever the gaps; a `--date` that is not real, a DB that cannot be opened or read, or a DATABASE_URL that is not SQLite exits 2.
