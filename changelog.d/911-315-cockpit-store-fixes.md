- **Built (316 item 1, the ruled fix of Codex's second review):** (1) every store write runs under `cockpit/ledger`'s lease (`acquire({holder, ttlMs: 10000})`; the runtime has no release verb, so a lease lapses 10 s after its last grant, and a long write renews it); a busy lease writes nothing, retries after expiresAt or 2 s (whichever is sooner) up to 5 times, then says NOT saved and keeps the pending flag (kept in the browser too, so a page closed under a busy lease merges on reopen); one re-read of the header after the switch. (2) A set-aside counts only after its write returns; on a failure the records stay in the ledger ("SET-ASIDE FAILED (browser storage full) — N records kept in the ledger"), and a store write is built from the page's own last save when the browser refused the local copy (an older copy never reaches the store). (3) Each mirror load takes a sequence number; only the latest sets the note, the button or the slate.
