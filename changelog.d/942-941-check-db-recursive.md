## 2026-11-12 (#942: 941-check-db-recursive — the shared `--db` fence refuses a hard link to a file anywhere under data/, not only directly in it (#941; ARCHITECT 2026-11-11 19:50 ET, addendum 347 item 3).)
- **Ruling (verbatim, in part):** "The `check_db` gap you found (a hard link to a file in a SUBFOLDER of data/ passes the fence that every `--db` since 11-01 uses) is a finding in its own right: its own Issue and small PR (class finding), the fence walking data/ recursively by device and inode, a test with a link under data/backups/; before 11-17 as well."
- **Built (`mlb_pitchers_gate._data_tree`, read by `check_db`):**
  - The identity pass walks each data/ recursively and compares the target's `(st_dev, st_ino)` against every regular file found. A symlink to a file stats as that file, as the direct-child pass read it. A match is refused, naming the file, with the same "hard link into the repo's data/" refusal as before.
  - Folders reached through a symlink are walked (each visited once by device and inode, so a link loop cannot hold the walk). A path under a folder data/ links to is refused as under data/: with `data/backups -> /elsewhere/backups`, the literal `data/backups/<f>`, the real file and a hard link to it all used to pass. Code's pre-push review found this; it predates this PR.
  - Conservative unknowns (law 4): a folder or entry under data/ that cannot be read REFUSES, never a silent pass, and so does a tree too deep to walk (a RecursionError on Python before 3.12). A data/ that does not exist holds nothing, as before. A dangling symlink names no file.
- **Unchanged:** the resolved-path check, the configured-database check, the never-created check, and every caller (mlb-pitchers-gate, nfl-v2-gate, nfl-v2-fit, soccer-v23, the bulletin renderer, the receipt scripts, `intl-elo-confirm --db` once #938 merges).
- **Receipt:** the three `test_941_*` tests in `tests/test_mlb_pitchers_v1.py`, run in a scratch `DATA_DIR`, never the repo's data/: the link under `data/backups/` (at depth, and in data/ itself), the folder data/ links to, and what the walk cannot read. Each fails on main.
