## 2026-10-19 (#PRNUM: book-source-times — ARCHITECT addendum 137 item 4; Refs #615)
- The ruling, verbatim: "MLB's and PL's odds syncs never store the provider's update time (`_mlb_store_odds`, `sync_odds`), so their stamp age cannot be measured. Issue + a small data PR: both syncs write `source_updated_at` from the provider's own update field, as `sync-odds-football` does, no backfill; the 24-hour rule then applies to them forward."
- src/ingestion/service.py: `_mlb_store_odds` and `IngestionService.sync_odds` write `source_updated_at` as `sync_odds_nfl` does, through the new `_write_book_source_times`. Each odds row gets the time its own adapter row carries (None = unknown, never our clock). Each appended book snapshot gets the oldest over the rows its close priced (`close.priced_rows`; one unknown row makes it unknown). The write is guarded Core SQL after a flush, so a database before `migrate_odds_source_updated_at.py` writes nothing to the field. `sync-odds --competition NFL|NCAA` (the american-football adapter, whose rows carry the ruled `response[].update`) now stamps its rows and snapshots too.
- src/walters/close.py: `priced_rows(cl)`, extracted from `book_stamp`: the complete books' outcome rows of a close's session, or its snapshot legs. The writers stamp a snapshot from the same set `book_stamp` reads, so the odds close and the snapshot close of one game read one stamp.
- src/walters/export.py `results_tally` (#615 comment 6270315541): the verified / retained-legacy split loads snapshots with `kalshi_close_market_filter`, as `clv_restate.restate()` does. A divergence stored against a close priced from a Kalshi mid (the 2026-10-05 `kalshi_only` close, or the stale-book rule's `kalshi`) reproduces and counts as VERIFIED. **This moves RESULTS.md's MLB cohort counts on the day it merges**, for every stored outcome in the window: Kalshi-only MLB divergences read retained-legacy before. Soccer (PL) cannot move, because a three-way board never takes a Kalshi close. The RESULTS.md divergence paragraph says so, and no longer calls the M11 rollover games unpriced (they grade against the Kalshi-only mid since 2026-10-05).
