- **Ruling (verbatim):**
  > "For a game of a closing family the close is its closing page. The rule of 2026-09-28 stands: a position is
  > claimed at its first call and executed at the close.
  > A closing run whose page went out writes exports/closing_<FAMILY>_<start>.json: the games on its page and no
  > other, each row as the run's export gave it, and a closing block naming the family, the start time, the run id

  > A closing run does not write, replace or move the family's slate file. The slate chains write it, as they did

  > In the ledger a position is executed where its closing file calls it. A claim that the closing page does not

  > gate sizing. A shadow follows the same rule."
