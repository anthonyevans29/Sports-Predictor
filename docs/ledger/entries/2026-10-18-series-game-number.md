  - **From each game's own entry.** The statsapi adapter reads the four fields from each /schedule game (`series_fields`) and carries them on `NormalizedMatch.series`. Every other adapter leaves that None, and nothing is written for its rows.
    - A field the entry does not give is NULL, never another game's (law 4). So is one it gives in a shape the adapter does not read: a number given as text or as a decimal, a true/false, an empty or blank text, a time with no zone or with spaces around it.
    - Each field is read as the entry gives it: a number is never read from text (`"5"` is NULL, not 5) and a text is stored as given, never trimmed. An empty or blank description is NULL.
    - A game listed twice in one answer keeps its last entry's fields, the one its status and kickoff were last written from. On the ALCS shape that is the rescheduled entry, Game 5 of 7.
