- **Readings, for the architect's read:**
  - **"Unstarted at its exported_at" is read by kickoff time** (the stored start after `exported_at`), never by status: the status is now's, and a game finished since was unstarted when an earlier file was written.
  - **"Such a file" (item 5) is the newest file exported BEFORE the ET day that would count but for its export day** (desk calls, every game of the day unstarted at its `exported_at`). A file that could not count either way is not named. It is named first in the brackets of each NO SLATE FILE line, the refused and block lines included (the declared text is the due line's).
  - **Which file stands, of several that count (the review's freshen case):** the one holding the most of the day's games, then the newest. A freshen after the first kickoff writes a file without the started game; the morning file still holds it with its calls, and it stands, so `started before it` never names a game the slate did cover. As built on base the newest stood; this is a reading, and the newest-first rule is a one-line change back.
  - **Item 4 read literally:** a file of the day exported after every kickoff holds "every game of the day UNSTARTED at its exported_at" vacuously, and it counts when it holds at least one game of the day (each game it has no row for is named `started before it`); a file with no row for any game of the day (tomorrow's file, say, exported late tonight) is no slate file of the day, and the gap stands.
  - **Item 8's counts cover every call kind**: PLAY, PASS, LADDER and `no desk call` count the day's rows (by name, as built); `+k` counts the rest. A row of a game of the day called off (POSTPONED, CANCELLED, STALE_ORPHAN: the MLB export keeps a postponed game's row) is a game of the day and no game: in neither the counts nor k. The receipt's `rows` and `calls` are the page's (the day's), and `beyond_day` is k.
  - **The LATE line now prints for any run that starts more than a minute after its due time**: a retry after a failed attempt, a run after a miss or a hold, a deferred slate. A slate deferred or held one tick runs at the next tick, normally a few seconds past one cadence, so it reads `LATE 1 min` (the ruling's words, "more than one cadence"); only a run exactly one cadence after the due time, to the second, is on time. The receipt's `late_minutes` is the whole minutes after the due time either way (`late` says whether the line printed).

The next tick is the first after the tick's run ends, so "a minute later" is the run's length plus a minute.
