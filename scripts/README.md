# scripts/ — the index

Every file under `scripts/` (`git ls-files scripts`), one line each: what it does, the lane or Issue it serves,
its kind, and the receipt the kind rests on (ARCHITECT 2026-11-06, addendum 276 item 3, PR C). Each purpose is read
from the file's own docstring or header. The lane or Issue comes from the file itself or from the commit that added
it (`git log --diff-filter=A -- <path>`); an Issue number appears only where the file, that commit or a cited record
names one. A caller is named by its file and line (`git grep`). This index describes and decides nothing (addendum
276 item 2(b)): no deletion in PR C; the ONE-OFF list is the input to a later ruling (276 item 3), and tests/ stays
untouched. Rules live in CLAUDE.md and CONTRIBUTING.md; the docs/ index is docs/README.md.

Kinds (addendum 276 item 3): **LIVE**, called by a chain, a block or CI; **TOOL**, a probe or receipt script kept
for re-runs; **ONE-OFF**, ran once, its receipt named. **UNDETERMINED** (listed last) is a file whose run or keep
has no record found: the line says what was searched, for the same later ruling.

- `scripts/README.md` — this index. Addendum 276 item 3 (PR C). Not a script, so no kind.

Counts: 114 scripts indexed; LIVE 10, TOOL 63, ONE-OFF 29, UNDETERMINED 12 (counted from the sections below, #830's probe PR; `git ls-files scripts` holds 115: `scripts/cockpit_build.py` is not yet indexed). A script a test runs (imported, or as a subprocess) is TESTED, not LIVE: CI runs its tests, never its job; a script another kept script loads is a TOOL (a dependency), never ONE-OFF.
